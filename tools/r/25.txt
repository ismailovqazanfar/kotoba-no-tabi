LESSON 25: Hər şey üçün minnətdaram

== GRAMMAR ==
G1. Keçmiş zamanın sadə forması ら、〜 | meaning: "əgər ..., ..." (şərt)
 pattern: sadə keçmiş forma ら、 baş cümlə
 explanation: "Əgər" demək üçün ən universal yol: sadə keçmiş formaya ら əlavə etmək. 行った → 行ったら – getsəm, getsən.sözqaydanümunəfeilた-forma + ら雨 が 降ったら – yağış yağsainkarなかった + ら行かなかったら – getməsənい-sifətかった + ら安かったら – ucuz olsaな-sifət / isimだった + らひまだったら・雨だったら雨 が 降ったら、行きません。Yağış yağsa, getmirəm.ひま だったら、遊び に 来て ください。Boş olsan, qonaq gəl.〜たら-nın ən böyük üstünlüyü: ikinci hissədə istənilən şey ola bilər: arzu, xahiş, dəvət, fikir. 23-cü dərsdəki と bunu bacarmırdı. Ona görə gündəlik danışıqda "əgər" deyəndə ən çox たら işlənir.Asan yadda saxlamaq: た-formanı bilirsən? Deməli, 〜たら-nı da bilirsən. Sadəcə sonuna ら əlavə et!Məşq: şərt formasını deyin行きますIkimasu〜たら formasını özünüz deyinGöstərNövbəti feil →
 ex: お金が あったら、旅行します。 = Pulum olsa, səyahətə gedərəm.
 ex: 時間が なかったら、~テレビを 見ません。 = Vaxtım olmasa, televizora baxmıram.
 ex: 安かったら、~パソコンを 買いたいです。 = Ucuz olsa, kompüter almaq istəyirəm.
 ex: 暇だったら、手伝って ください。 = Vaxtınız olsa, zəhmət olmasa, kömək edin.
 ex: いい 天気だったら、散歩しませんか。 = Hava yaxşı olsa, gəzməyə çıxaq?
G2. F た-forma ら、〜 | meaning: "... olanda, ... edən kimi"
 pattern: Fた-forma ら、 baş cümlə
 explanation: Bəzən birinci hadisənin baş verəcəyi mütləqdir: "evə çatanda", "qış gələndə". Onda 〜たら "əgər" yox, "...olanda, ...edən kimi" mənasını verir.うち に 着いたら、電話 します。Evə çatanda zəng edəcəyəm.10時 に なったら、出かけましょう。Saat 10 olanda çıxaq.Evə çatacağın məlumdur, sual sadəcə "nə vaxt?"dır. Ona görə buradakı たら şərt deyil, ardıcıllıqdır: "əvvəl bu, sonra o".Fərq hiss et: 雨 が 降ったら – "yağış yağsa" (bilinmir), 春 に なったら – "yaz gələndə" (mütləq gələcək).
 ex: 10時に なったら、出かけましょう。 = Saat 10 olanda çıxaq.
 ex: うちへ 帰ったら、すぐ ~シャワーを 浴びます。 = Evə gələn kimi dərhal duş qəbul edirəm.
G3. F て-forma / F ない → なくて / い-SİF → くて / な-SİF → で / İS で も、〜 | meaning: "... olsa da, ... olmasına baxmayaraq"
 pattern: て-forma も、 baş cümlə
 explanation: Güzəşt: "...olsa da, ...olmasına baxmayaraq". Gözlənilən nəticə baş vermir. Qoşulma て-formaya bənzəyir, sadəcə も əlavə olunur:sözqaydanümunəfeilて-forma + も降って もinkarなくて + も行かなくて もい-sifətくて + も安くて もな-sifət / isimで + も便利で も・日曜日で も雨 が 降って も、行きます。Yağış yağsa da, gedirəm.高くて も、買いたい です。Baha olsa da, almaq istəyirəm.Cüt öyrən: 降ったら (yağsa → getmirəm) və 降っても (yağsa da → gedirəm). Bir hərf fərqi, tam əks nəticə!Məşq: 〜ても formasını deyin降りますFurimasu〜ても formasını özünüz deyinGöstərNövbəti feil →
 ex: 雨が 降っても、洗濯します。 = Yağış yağsa da, paltar yuyuram.
 ex: 安くても、わたしは ~グループ旅行が 嫌いです。 = Ucuz olsa da, qrupla səyahəti xoşlamıram.
 ex: 便利でも、~パソコンを 使いません。 = Rahat olsa da, kompüterdən istifadə etmirəm.
 ex: 日曜日でも、働きます。 = Bazar günü olsa da, işləyirəm.
G4. もし | meaning: "əgər" (fərziyyəni vurğulayır)
 pattern: もし 〜たら
 explanation: もし "əgər" sözüdür və 〜たら cümləsinin əvvəlinə qoyulur. Qrammatik olaraq vacib deyil, amma qarşı tərəfə xəbər verir: "indi fərziyyə gəlir!"もし 1億円 あったら、何 を しますか。Əgər 100 milyon yenin olsa, nə edərdin?もし 雨 だったら、中止 です。Əgər yağış olsa, ləğv olunur.Söhbət oyunu: もし 生まれ変わったら、何 に なりたい？ – "əgər yenidən doğulsaydın, nə olmaq istərdin?" Yapon dostlarla çox maraqlı söhbət başlanğıcıdır.
 ex: もし 1億円 あったら、いろいろな 国を 旅行したいです。 = Əgər yüz milyon yenim olsaydı, müxtəlif ölkələrə səyahət etmək istərdim.
G5. Budaq cümlənin mübtədası | meaning: が ilə
 pattern: 
 explanation: Budaq cümlədə (〜とき, 〜と, 〜まえに, 〜たら, 〜ても) mübtəda が ilə gəlir, は ilə yox.友だち が 来たら、出かけます。Dostum gələndə çıxacağam.わたし が 帰る まえに、掃除 して ください。Mən qayıtmazdan əvvəl təmizlik edin.Səbəb sadədir: は bütün cümlənin mövzusunu göstərir. Budaq cümlə isə sadəcə "şərait"dir, öz mövzusu ola bilməz. 22-ci dərsdəki təyin cümləsi qaydası ilə eyni məntiq.Ümumi qayda: "kiçik cümlə" içində mübtəda həmişə が. Bunu yadda saxlasan, uzun cümlələrdə çaşmayacaqsan.
 ex: 友達が 来る まえに、部屋を 掃除します。 = Dostlarım gəlməzdən əvvəl otağı yığışdıracağam. (18-ci dərs)
 ex: 妻が 病気の とき、会社を 休みます。 = Arvadım xəstələnəndə işə getmirəm. (23-cü dərs)
 ex: 友達が 約束の 時間に 来なかったら、どうしますか。 = Dostunuz razılaşdığınız vaxtda gəlməsə, nə edərsiniz?
