LESSON 16: Necə istifadə etməli?

== GRAMMAR ==
G1. Cümlələri birləşdirmək | meaning: て-forma ilə
 pattern: 
 explanation: て-forma cümlələri "zəncir" kimi birləşdirir: bir neçə hərəkəti ardıcıl sadalamaq üçün sonuncudan başqa bütün feillər て-formada olur.朝 起きて、シャワー を 浴びて、会社 へ 行きます。Səhər oyanıram, duş qəbul edirəm və işə gedirəm.きのう 買い物 を して、映画 を 見ました。Dünən alış-veriş etdim və kino izlədim.Bütün cümlənin zamanını sonuncu feil həll edir. Birinci nümunədə 行きます (indiki), ikincidə 見ました (keçmiş). て-forma özü zaman daşımır, sadəcə "və sonra" deyir.Sifətləri də birləşdirmək olar: い-sifət い → くて, な-sifət və isim で alır: 安くて おいしい – ucuz və dadlı; 静か で きれい – sakit və təmiz.Ardıcıllıq vacibdir: て ilə bağlanan hərəkətlər həqiqətən baş verdiyi sıra ilə deyilir. Yəni "duş aldım, oyandım" desən, gülməli alınar.
 ex: 朝 ~ジョギングを して、~シャワーを 浴びて、会社へ 行きます。 = Mən səhərlər qaçıram, duş qəbul edirəm və işə gedirəm.
 ex: 神戸へ 行って、映画を 見て、お茶を 飲みました。 = Kobeyə getdim, filmə baxdım və çay içdim.
G2. F₁ て-forma から、F₂ | meaning: "F₁ edəndən sonra F₂"
 pattern: F₁て-forma から、 F₂
 explanation: て-forma + から – "...edəndən sonra". Birinci hərəkət bitir, sonra ikincisi başlayır. Çox vaxt birinci hərəkət ikinci üçün hazırlıqdır.手 を 洗って から、食べます。Əllərimi yuyandan sonra yeyirəm.仕事 が 終わって から、飲み に 行きましょう。İş bitəndən sonra içməyə gedək.Sadə て-zəncirindən fərqi: から ardıcıllığı vurğulayır: "əvvəlcə bu, ancaq sonra o". Valideynlərin "əvvəl dərsini et, sonra oyna" cümləsi tam bu qəlibdir: 宿題 を して から、遊びなさい.Tələ: 9-cu dərsdəki 〜から ("çünki") ilə qarışdırma. Bura て-formadan sonra gəlir və "sonra" deməkdir.
 ex: お金を 入れてから、~ボタンを 押して ください。 = Pulu qoyandan sonra, zəhmət olmasa, düyməni basın.
G3. İS₁ は İS₂ が SİF | meaning: "İS₁-in İS₂-si ...-dır"
 pattern: İS₁ は İS₂ が SİF
 explanation: Bir şeyin hissəsini təsvir etmək üçün: İS₁ は İS₂ が SİF. "Fil – burnu uzundur" məşhur yapon nümunəsidir: 象 は 鼻 が 長い です.大阪 は 食べ物 が おいしい です。Osakanın yeməkləri dadlıdır.ソフィア さん は 髪 が 長い です。Sofiyanın saçları uzundur.は ümumi mövzunu ("Osaka haqqında danışırıq"), が isə konkret hissəni ("yeməkləri") göstərir. Azərbaycan dilində "Osakanın yeməkləri" deyirik, yaponcada isə "Osaka – yeməkləri dadlı".Faydalı qəlib: insanları təsvir etmək üçün əladır: 目 が 大きい (gözləri böyük), 背 が 高い (boyu uzun).
 ex: 大阪は 食べ物が おいしいです。 = Osakada yeməklər dadlıdır.
 ex: ドイツの フランケンは ~ワインが 有名です。 = Almaniyanın Franken bölgəsi şərabı ilə məşhurdur.
 ex: ソフィアさんは 髪が 長いです。 = Sofiyanın saçları uzundur.
G4. İS を F | meaning: çıxış nöqtəsi
 pattern: yer を 出ます / 降ります
 explanation: Bir yerdən çıxmaq, nəqliyyatdan düşmək haqqında danışanda çıxış nöqtəsi を ilə göstərilir: 部屋 を 出ます – otaqdan çıxıram.7時 に うち を 出ます。Saat 7-də evdən çıxıram.電車 を 降ります。Qatardan düşürəm.Yəqin təəccübləndin: "-dan" üçün から gözləyirdin, hə? Burada を hərəkətin "üstündən keçdiyi" yeri bildirir. Qatara minmək に, qatardan düşmək を: güzgü cütü!Cüt öyrən: 電車 に 乗ります ↔ 電車 を 降ります, 部屋 に 入ります ↔ 部屋 を 出ます.
 ex: 7時に うちを 出ます。 = Saat 7-də evdən çıxıram.
 ex: 梅田で 電車を 降りました。 = Umeda stansiyasında qatardan düşdüm.
G5. どうやって | meaning: "necə? hansı yolla?"
 pattern: どうやって F か
 explanation: どうやって – "necə? hansı yolla?". Marşrutu və ya bir işin üsulunu soruşur. Cavabda adətən て-zəncir gəlir.大学 まで どうやって 行きます か。Universitetə necə gedirsən?駅 から 3番 の バス に 乗って、大学前 で 降ります。Stansiyadan 3 nömrəli avtobusa minib universitet dayanacağında düşürəm.Yol soruşanda: 駅 まで どうやって 行きますか – "stansiyaya necə gedim?". Yaponiyada mütləq lazım olacaq ifadə.
 ex: 大学まで どうやって 行きますか。 = Siz universitetə necə gedirsiniz?
 ex: ……京都駅から 16番の ~バスに 乗って、大学前で 降ります。 = ……Kioto stansiyasından 16 nömrəli avtobusa minirəm və Daygaku-mae dayanacağında düşürəm.
G6. どれ / どの İS | meaning: "hansı?" (üç və daha çox arasında)
 pattern: 
 explanation: Üç və daha çox şey arasından seçim üçün どれ (tək işlənir) və どの + isim. İki şey arasında isə 12-ci dərsdəki どちら.söznecə işlənir?nümunəどれtək, "hansı?"どれ が いい です かどのisimdən əvvəlどの 人 が 田中 さん です かどちらiki variantdanどちら が いい です かko-so-a-do yenə: どれ/どの cədvəldə これ/この ilə eyni sırada idi (3-cü dərs). Sistem işləyir!
 ex: パーカーさんの 傘は どれですか。 = Cənab Parkerin çətiri hansıdır?
 ex: ……あの 青い 傘です。 = ……O göy çətirdir.
 ex: ラモスさんは どの 人ですか。 = Onlardan hansı cənab Ramosdur?
 ex: ……あの 背が 高くて、髪が 黒い 人です。 = ……O ucaboy, qarasaçlı kişi.
G7. F-ます-kökü + 方 | meaning: "…mə qaydası, necə …"
 pattern: F-ます 方
 explanation: Feili "qayda, üsul" isminə çevirmək üçün ます-köklə 方（かた） birləşir: 使います → 使い方 – istifadə qaydası.この 機械 の 使い方 を 教えて ください。Bu maşının istifadə qaydasını öyrədin.漢字 の 読み方kanjinin oxunuş qaydasıFeil artıq isim olduğu üçün obyekt を ilə yox, の ilə bağlanır: 漢字 の 読み方. します feillərində isə 仕方 işlənir: 勉強 の 仕方 – dərs oxuma üsulu.Dükanda faydalı: 使い方 を 教えて ください – "bunu necə istifadə edim?" Elektronika alanda mütləq soruşacaqsan.
 ex: この 機械の 使い方を 教えて ください。 = Bu cihazın istifadə qaydasını öyrədin, zəhmət olmasa.
 ex: この 漢字の 読み方が わかりません。 = Bu kanjinin oxunuşunu bilmirəm.
G8. 〜て きます | meaning: "gedib … gəlmək"
 pattern: F-て きます
 explanation: 〜て きます – "gedib ...gəlmək". Bir yerə gedirsən, işi görürsən və geri qayıdırsan. Yaponlar qısa müddətə çıxanda tez-tez deyir:ちょっと 買って きます。Gedib bir şey alıb gəlirəm.いって らっしゃい。Get, gəl. (yola salma)Mədəni ritual: evdən çıxanda 行って きます ("gedib gəlirəm"), qalanlar 行って らっしゃい deyir. Qayıdanda ただいま, cavab おかえりなさい. Bu dörd ifadə yapon evinin "musiqisi"dir.
 ex: ちょっと ~コンビニで 飲み物を 買って きます。 = Marketdən içki alıb gəlirəm.
 ex: ……いって らっしゃい。 = ……Yaxşı get-gəl.
