LESSON 3: Hardadır?

== GRAMMAR ==
G1. ここ / そこ / あそこ / こちら / そちら / あちら | meaning: "bura / ora / ora" və "bu tərəf / o tərəf"
 pattern: 
 explanation: Əşyalar üçün これ/それ/あれ vardı, yerlər üçün də onların "qohumları" var: ここ, そこ, あそこ. Məntiq tamamilə eynidir, sadəcə indi əşyanı yox, yeri göstəririk.sözoxunuşumənasıここkokobura, mənim olduğum yerそこsokoora, sənin olduğun yerあそこasokoora, ikimizdən də uzaq yerBir də こちら, そちら, あちら var. Əslində "bu tərəf, o tərəf" deməkdir, amma gündəlik həyatda ən çox nəzakətli "bura, ora" kimi işlənir. Mağazada, oteldə, ofisdə işçilər sənə yolu göstərəndə məhz bunları eşidəcəksən: エレベーター は あちら です – lift o tərəfdədir.Maraqlı detal: sən və dostun eyni otaqdasınızsa, ikinizin olduğu yer ここ olur. Onda そこ yaxınlıqdakı yeri, あそこ uzaqdakı yeri bildirir.
G2. İS₁ は İS₂ (məkan) です | meaning: "İS₁ İS₂-dadır"
 pattern: İS₁ は məkan です
 explanation: Bir şeyin harada olduğunu demək üçün yeni model öyrənməyə ehtiyac yoxdur: 1-ci dərsdəki 〜は 〜です burada da işləyir. Sadəcə xəbər yerinə məkan qoyursan və です avtomatik olaraq "-dadır, -dədir" mənasını alır.トイレ は あそこ です。Tualet oradadır.加藤 さん は 会議室 です。Kato iclas otağındadır.Gördün? Eyni qəlib, yeni məna. Yapon dili bu cür "qənaətcil"dir: az qayda, çox istifadə.Tələ: 加藤さん は 会議室 です deyəndə "Kato iclas otağıdır" kimi başa düşmə. Kontekst aydındır: söhbət onun harada olduğundan gedir.
 ex: お手洗いは あそこです。 = Ayaqyolu oradadır.
 ex: 電話は 2階です。 = Telefon ikinci mərtəbədədir.
 ex: 原田さんは 事務所です。 = Cənab Harada ofisdədir.
G3. どこ / どちら | meaning: "harada?" / "hansı tərəfdə?"
 pattern: İS は どこですか
 explanation: Yer soruşmaq üçün どこ (harada?) işlədirsən. どちら isə əslində "hansı tərəf?" deməkdir, amma nəzakətli danışıqda どこ-nun yerinə də keçir.トイレ は どこ です か。Tualet haradadır? (adi)お国 は どちら です か。Hansı ölkədənsiniz? (çox nəzakətli)İkinci cümlə çox maraqlıdır: "Ölkəniz hansı tərəfdədir?" kimi səslənir, amma əslində "haralısınız?" sualının ən nəzakətli formasıdır. Tanış olanda yaponlar bunu çox soruşur.Məsləhət: dostla どこ, tanımadığın böyüklə və ya müştəri ilə どちら işlət. Məna eynidir, fərq hörmətdədir.
 ex: お手洗いは どこですか。 = (Zəhmət olmasa, deyin) ayaqyolu hardadır?
 ex: ……あそこです。 = ……Orada.
 ex: ~エレベーターは どちらですか。 = Lift hansı tərəfdədir? yəni
 ex: ……あちらです。 = ……O tərəfdə.
G4. İS₁ の İS₂ | meaning: "haranın məhsulu"
 pattern: ölkə / şirkət の məhsul
 explanation: の yenə səhnədədir! Bu dəfə "haranın məhsulu?" sualına cavab verir. Birinci isim ölkə və ya şirkət, ikincisi isə məhsul olanda の "orada istehsal olunub" mənasını verir.日本 の 車Yaponiya maşını, yapon istehsalıミドリ商事 の カメラMidori Shouji-nin kamerasıSoruşanda どこ の deyirsən: これ は どこ の 時計 です か – Bu haranın saatıdır? Cavab: スイス の です – İsveçrənindir.Fikir ver: sonuncu cavabda ismi atdıq (スイス の です). 2-ci dərsdəki "-ınkı" qaydası burada da işləyir.
 ex: これは どこの ~コンピューターですか。 = Bu kompüter harada istehsal olunub?
 ex: ……日本の ~コンピューターです。 = ……Bu, yapon kompüteridir.
 ex: ……アオゾラ電気の ~コンピューターです。 = ……Bu, Aozora Denki şirkətinin kompüteridir.
G5. こ・そ・あ・ど sistemi | meaning: işarə əvəzliklərinin ümumi cədvəli
 pattern: 
 explanation: İndiyə qədər öyrəndiyin bütün işarə sözləri əslində bir böyük sistemin hissələridir. Yaponlar buna sadəcə ko-so-a-do deyir. Sözün birinci hecası məsafəni, qalan hissəsi isə nəyi göstərdiyini bildirir.こ · mənə yaxınそ · sənə yaxınあ · uzaqど · sualəşyaこれそれあれどれ+ isimこのそのあのどのyerここそこあそこどこtərəf (nəzakətli)こちらそちらあちらどちらBu cədvəli bir dəfə başa düşsən, onlarla sözü avtomatik bilmiş olursan. Məsələn, "どれ" hansı deməkdir? Cədvələ bax: sual sırası + əşya sətiri, yəni "hansı (əşya)?".Kiçik istisna: あ sətirində "あこ" yox, あそこ deyilir. Bunu ayrıca yadda saxla.
G6. お〜 | meaning: ehtiram prefiksi
 pattern: お İS
 explanation: 2-ci dərsdə gördüyümüz お prefiksi burada qarşı tərəfə hörməti göstərmək üçün işlənir. Sənə yox, həmsöhbətinə və ya üçüncü şəxsə aid olan şeyə qoşulur.お国 は どちら です か。Ölkəniz haradır?お名前 は？Adınız?Öz ölkənə, öz adına お qoymursan. Bu, özünü tərifləmək kimi səslənir. Yəni わたし の お国 desən, gülməli olar.Qayda sadədir: お = "sizin" deməyin nəzakətli yolu. Özün haqqında danışanda onu at.
 ex: ［お］国は どちらですか。 = Siz hansı ölkədənsiniz?
