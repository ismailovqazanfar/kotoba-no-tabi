LESSON 23: Necə gedim?

== GRAMMAR ==
G1. F-lüğət / F ない / い-SİF / な-SİF な / İS の とき、〜 | meaning: "... olanda, ... edəndə"
 pattern: F / SİF / İS とき、 baş cümlə
 explanation: とき – "...olanda, ...edəndə". とき əslində isimdir ("vaxt"), ona görə ondan əvvəlki sözlər 22-ci dərsdəki təyin qaydası ilə qoşulur:söznümunəmənasıfeil本 を 借りる ときkitab götürəndəinkarわからない ときbaşa düşməyəndəい-sifətさびしい ときdarıxandaな-sifətひま な ときboş vaxtı olandaisim子ども の ときuşaq olandaわからない とき、先生 に 聞きます。Başa düşməyəndə müəllimdən soruşuram.子ども の とき、よく 海 で 泳ぎました。Uşaq olanda tez-tez dənizdə üzərdim.Fikir ver: isim の, な-sifət な ilə qoşulur. Təyin qaydası dəyişmir!
 ex: 図書館で 本を 借りる とき、~カードが 要ります。 = Kitabxanadan kitab götürəndə qeydiyyat kartı lazımdır.
 ex: 使い方が わからない とき、わたしに 聞いて ください。 = Necə istifadə edildiyini bilməyəndə məndən soruşun.
 ex: 体の 調子が 悪い とき、「元気茶」を 飲みます。 = Özümü pis hiss edəndə “Genki-ça” içirəm.
 ex: 暇な とき、うちへ 遊びに 来ませんか。 = Boş vaxtınız olanda bizə qonaq gəlməzsiniz?
 ex: 妻が 病気の とき、会社を 休みます。 = Arvadım xəstələnəndə işə getmirəm.
 ex: 若い とき、あまり 勉強しませんでした。 = Cavanlıqda az dərs oxuyurdum.
 ex: 子どもの とき、よく 川で 泳ぎました。 = Uşaqlıqda tez-tez çayda üzürdüm.
G2. F-lüğət forması / F た-forma とき、〜 | meaning: hərəkət bitib, yoxsa yox?
 pattern: 
 explanation: Burada incə, amma çox vacib bir fərq var: とき-dən əvvəl lüğət forması, yoxsa た-forma? Fərq zamanda deyil, ardıcıllıqdadır.formamənası日本 へ 行く ときYaponiyaya getməzdən əvvəl / yolda日本 へ 行った ときYaponiyaya çatanda, orada olarkən日本 へ 行く とき、カメラ を 買いました。Yaponiyaya gedəndə (getməzdən əvvəl) kamera aldım.日本 へ 行った とき、カメラ を 買いました。Yaponiyaya gedəndə (orada) kamera aldım.Hər iki cümlədə "aldım" keçmişdir, amma kameranın harada alındığı fərqlidir! Birincidə evdə, ikincidə Yaponiyada. Yaponca bu fərqi forma ilə dəqiq göstərir, Azərbaycan dilində isə izah etmək lazımdır.Gündəlik nümunə: うち を 出る とき (evdən çıxarkən, ayaqqabını geyinərkən) və うち に 帰った とき (evə girəndə). Yaponlar evə girəndə ayaqqabını çıxarır, bu cümlə də o anı təsvir edir.
 ex: パリへ 行く とき、かばんを 買いました。 = Parisə getməzdən əvvəl (yolda) çanta aldım.
 ex: パリへ 行った とき、かばんを 買いました。 = Parisdə olanda çanta aldım.
G3. F-lüğət forması と、〜 | meaning: "... etsəniz, ... olur" (qaçılmaz nəticə)
 pattern: F-lüğət forması と、 nəticə
 explanation: Lüğət forması + と – "...etsən, ...olur". Birinci hərəkət baş verəndə ikinci təbii olaraq, mütləq baş verir. Maşının işləməsini, yolu izah edəndə çox işlənir.この ボタン を 押す と、お釣り が 出ます。Bu düyməni bassan, qalıq pul çıxır.まっすぐ 行く と、右 に 駅 が あります。Düz getsən, sağda stansiya var.Bu, "əgər" deyil, "hər dəfə belə olur" qanunudur. Avtomat, mexanizm, təbiət hadisəsi kimi: düyməni basırsan → nəticə həmişə gəlir.Tələ: bu qəlibdə ikinci hissədə arzu, xahiş, dəvət olmur. 春 に なる と、花見 に 行きましょう desən səhvdir. Bunun üçün başqa şərt formaları lazımdır (25-ci dərs).
 ex: この ~ボタンを 押すと、お釣りが 出ます。 = Bu düyməni bassanız, qalıq pul çıxacaq.
 ex: これを 回すと、音が 大きく なります。 = Bunu çevirsəniz, səs artacaq.
 ex: 右へ 曲がると、郵便局が あります。 = Sağa dönsəniz, poçt şöbəsini görəcəksiniz.
G4. İS が SİF | meaning: gördüyümüzü təsvir edirik
 pattern: İS が SİF
 explanation: 14-cü dərsdə gördük: gözünlə gördüyün hadisəni が ilə təsvir edirsən. Bu, sifətli cümlələrə də aiddir: この 店 は 静か です (ümumi fikir) yox, 音 が 小さい です (səsin özü, indi hiss etdiyim).あ、雪 が きれい です ね。Ah, qar nə gözəldir!この 部屋 は 窓 が 大きい です。Bu otağın pəncərəsi böyükdür.Kamera kimi: が "bu an, gözümün qabağında" deyir. Bir mənzərəni ilk dəfə görəndə təbii reaksiya budur.
 ex: 音が 小さいです。 = Səs zəifdir.
G5. İS を F (hərəkət) | meaning: "... boyunca, ... -dan keçərək"
 pattern: yer を 渡ります / 散歩します
 explanation: Hərəkət feilləri (さんぽします, わたります, あるきます, まがります) ilə を keçilən yeri göstərir: "boyunca, ...dan keçərək".公園 を 散歩します。Parkda gəzirəm. (parkın içindən keçərək)橋 を 渡って、右 へ 曲がって ください。Körpünü keçin və sağa dönün.Yol izahında bu qəlib əvəzsizdir: この 道 を まっすぐ 行って – bu yolla düz gedin. "Yolla" deyirik, yaponlar "yolu" deyir.16-cı dərsdən fərq: orada を "çıxış nöqtəsi" idi (部屋 を 出ます). Burada "keçilən yer"dir. Hər ikisi hərəkətin "üstündən keçdiyi" yerdir.
 ex: 公園を 散歩します。 = Parkda gəzirəm. (13-cü dərs)
 ex: 道を 渡ります。 = Yolu keçirəm.
 ex: 交差点を 右へ 曲がります。 = Kəsişmədə sağa dönürəm.
