LESSON 32: Yaponca danışa bilir oldum

== GRAMMAR ==
G1. 〜ために | meaning: ... üçün (məqsəd)
 pattern: lüğət forması / ad の ために、〜
 explanation: 〜ために – "...üçün" (məqsəd). İradə ilə etdiyin hərəkətin məqsədini deyirsən.家 を 買う ために 貯金して います。Ev almaq üçün pul yığıram.健康 の ために 毎朝 走って います。Sağlamlıq üçün hər səhər qaçıram.İki şərt var: 1) hərəkət iradə ilə edilir (almaq, getmək, öyrənmək); 2) hər iki hissənin mübtədası eyni şəxsdir. İsimdən sonra の: 家族 の ために – ailə üçün (ailənin xeyrinə).Gözəl cümlə: 好きな 人 の ために – "sevdiyim insan üçün" nə qədər çox fədakarlıq edirsən!
 ex: 留学する ために、英語を 勉強して います。 = Xaricdə oxumaq üçün ingilis dili öyrənirəm.
 ex: 子どもの ために 絵本を 買いました。 = Uşaq üçün şəkilli kitab aldım.
G2. 〜ように (məqsəd) | meaning: ... olsun deyə, ... üçün
 pattern: lüğət forması / ない-forma / bacarıq forması ように、〜
 explanation: 〜ように da "...üçün, ...olsun deyə" deməkdir, amma iradədən asılı olmayan vəziyyət, bacarıq və ya inkarla işlənir.ifadənə ilə?nümunə〜ためにiradəli hərəkət日本 へ 行く ために〜ようにbacarıq / vəziyyət / inkar日本語 が 話せる ように後ろ の 人 に も 見える ように、大きく 書きます。Arxadakılara da görünsün deyə, iri yazıram.忘れない ように、メモ します。Unutmayım deyə, qeyd edirəm.Test sualı: "Görünür" (見える) və "unutmamaq" (忘れない) sənin iradəndə deyil, ona görə ように. "Getmək" isə iradəlidir, ona görə ために.
 ex: 忘れない ように、手帳に 書いて おきます。 = Unutmayım deyə, dəftərçəyə yazıram.
 ex: 早く 治る ように、薬を 飲んで 寝ます。 = Tez sağalmaq üçün dərman içib yatıram.
G3. 〜ように なります / 〜ように して います | meaning: ... bilir oldum / ...-mağa çalışıram
 pattern: lüğət / bacarıq / ない-forma ように なります ／ して います
 explanation: 〜ように なりました – zamanla baş verən dəyişiklik: "...bilir oldum". Əvvəl bacarmırdım, indi bacarıram.日本語 が 話せる ように なりました。Yapon dilində danışa bilir oldum.コーヒー を 飲まなく なりました。Artıq qəhvə içmirəm.İnkar dəyişiklik üçün 〜なく なりました: "artıq ...mirəm". 〜ように して います isə məqsədli vərdişdir: 毎日 野菜 を 食べる ように して います – hər gün tərəvəz yeməyə çalışıram.Dil öyrənənin xoşbəxt anı: 漢字 が 読める ように なりました – "kanjini oxuya bilir oldum!" Bu cümləni tezliklə özün haqqında deyəcəksən.
 ex: 泳げる ように なりました。 = Üzə bilir oldum.
 ex: 最近 本を 読まなく なりました。 = Son vaxtlar kitab oxumuram.
 ex: 夜 12時前に 寝る ように して います。 = Gecə saat 12-dən əvvəl yatmağa çalışıram.
G4. 〜か / 〜かどうか | meaning: ...-ıb-ıbmadığını; nə/harada ... olduğunu
 pattern: sual sözü + sadə forma か ／ sadə forma かどうか
 explanation: Sualı böyük cümlənin içinə qoymaq: "...olub-olmadığını", "nə/harada... olduğunu".sual növüqəlibnümunəsual sözü var〜か何時 に 始まる か 知って います かhə/yox sualı〜か どうか合格できる か どうか 分かりませんどこ に 置いた か 忘れました。Harada qoyduğumu unutdum.本当 か どうか わかりません。Doğru olub-olmadığını bilmirəm.Kiçik qayda: な-sifət və isimdən sonra だ düşür: 本当 か どうか (本当だ かどうか yox).
 ex: 誰が 来るか まだ 分かりません。 = Kimin gələcəyi hələ məlum deyil.
 ex: この 話が 本当か どうか 調べて ください。 = Bu xəbərin doğru olub-olmadığını yoxlayın.
G5. 〜んです | meaning: axı ..., məsələ burasındadır ki ...
 pattern: sadə forma (な-sifət, ad: な) んです
 explanation: 〜んです – izah istəmək və ya vermək üçün. Gördüyün vəziyyətin səbəbini soruşursan, ya da öz vəziyyətini izah edirsən: "axı..., məsələ burasındadır ki...".どうした ん です か。Nə olub? (səndə qəribə bir şey görürəm)おなか が 痛い ん です。Qarnım ağrıyır axı.Sadə formadan sonra gəlir, な-sifət və isimdən sonra な: 暇 な ん です, 学生 な ん です. Yazıda 〜のです.Ehtiyatlı ol: hər cümlədə んです işlətsən, israrlı və emosional səslənir. Yalnız izah lazım olanda işlət.
 ex: 遅れて すみません。電車が 止まって いたんです。 = Gecikdiyim üçün bağışlayın. Qatar dayanmışdı.
 ex: 日本の ~アニメが 好きなんですか。 = Yapon animesini sevirsiniz, eləmi?
G6. 〜ので | meaning: ...-dığı üçün (yumşaq səbəb)
 pattern: sadə forma (な-sifət / ad: な) ので
 explanation: 〜ので – から kimi səbəb, amma daha yumşaq, obyektiv. Sanki hadisənin özü danışır, sən yox.熱 が ある ので、休みます。Qızdırmam olduğu üçün istirahət edirəm. (izah, nəzakətli)危ない から、触らないで。Təhlükəlidir, toxunma! (güclü)Üzr, izah, nəzakətli xahişdə ので seçilir. から isə öz qərarını güclü vurğulayır. ので-dən sonra əmr və sərt xahiş uyğun deyil. な-sifət və isimdən sonra な: 雨 な ので.İş yerində: gecikəndə 電車 が 遅れた ので、遅く なりました – "qatar gecikdiyi üçün, gecikdim". から desən, bəhanə kimi səslənər.
 ex: 電車が 遅れたので、会議に 間に合いませんでした。 = Qatar gecikdiyi üçün iclasa çatmadım.
 ex: 熱が あるので、今日は 休みます。 = Hərarətim olduğu üçün bu gün işə (dərsə) getməyəcəyəm.
 ex: この 辺は 静かなので、勉強しやすいです。 = Bu ərazi sakit olduğu üçün dərs oxumaq rahatdır.
G7. 〜おかげで / 〜せいで | meaning: ...-in sayəsində / ...-in günahı ilə
 pattern: sadə forma / ad の おかげで / せいで
 explanation: 〜おかげで / 〜せいで – ikisi də səbəbdir, amma nəticənin "rəngi" fərqlidir.ifadənəticənümunə〜おかげでyaxşı, minnətdarlıq先生 の おかげで 合格しました〜せいでpis, günahlandırma雨 の せいで 中止に なりましたİsimdən sonra の, feil və sifətdən sonra sadə forma. "Necəsən?" sualına yaponların klassik cavabı: おかげさまで – "sizin sayənizdə, yaxşıyam". Əslində sən heç nə etməmisən, amma bu, nəzakətdir!Qısa test: imtahandan keçdin, dostun kömək etmişdi → おかげで. Avtobus gecikdi və gecikdin → せいで.
 ex: 先生の おかげで、試験に 合格しました。 = Müəllimin sayəsində imtahandan keçdim.
 ex: 友達が 手伝って くれた おかげで、早く 終わりました。 = Dostumun köməyi sayəsində tez bitdi.
 ex: 雨の せいで、試合が 中止に なりました。 = Yağışın ucbatından oyun ləğv olundu.
G8. 〜とおりに | meaning: ...-dığı kimi, ...-a uyğun
 pattern: feil lüğət / た-forma / ad の とおりに
 explanation: 〜とおりに – "...dığı kimi, ...a uyğun". Bir şeyi dəqiq eynilə etmək.先生 が 言った とおりに 書いて ください。Müəllimin dediyi kimi yazın.説明書 の とおりに 組み立てました。Təlimata uyğun yığdım.Bəzi isimlərdən sonra どおり olur və の düşür: 時間 どおり (vaxtında), 予定 どおり (plana uyğun). Gözləntinin doğrulduğunu da bildirir: 思った とおり でした – düşündüyüm kimi oldu.Yaponiya simvolu: qatarlar 時間 どおりに gəlir. 1 dəqiqə gecikmə belə xəbərlərdə üzr istənilir!
 ex: 先生が 言った とおりに 書きました。 = Müəllimin dediyi kimi yazdım.
 ex: 地図の とおりに 歩いたら、駅に 着きました。 = Xəritədə göstərildiyi kimi gedəndə stansiyaya çatdım.
 ex: 時間どおりに 電車が 来ました。 = Qatar vaxtında gəldi.
G9. 〜という N | meaning: ...-adlı, ... deyilən
 pattern: ad / cümlə という ad
 explanation: 〜という N – "...adlı, ...deyilən". Tanımadığın söz, ad, yer haqqında danışanda.田中 さん という 人 から 電話 が ありました。Tanaka adlı birindən zəng oldu.「かんぴょう」って 何 です か。"Kanpyou" nədir?Danışıqda という → って olur. Yeni söz eşidəndə ən faydalı sual: 〜って 何 です か. Həmçinin 〜という 意味 – "...mənasını verir".Dil öyrənənin qızıl sualı: この 言葉 は どういう 意味 です か – "bu söz nə deməkdir?"
 ex: これは 「ぎょうざ」と いう 料理です。 = Bu "gyoza" adlı yeməkdir.
 ex: 田中さんと いう 人を 知って いますか。 = Tanaka adlı adamı tanıyırsınız?
 ex: 「しあわせ」と いう 言葉の 意味は 何ですか。 = "Şiavase" deyilən sözün mənası nədir?
G10. 〜ように 言う / 頼む | meaning: ...-sın deyə demək / xahiş etmək
 pattern: feil lüğət forması / ない-forma ように 言う / 頼む / 注意する
 explanation: 〜ように 言う / 頼む – başqasının sözünü dolayı yolla ötürmək: "...sın deyə dedi / xahiş etdi".先生 は レポート を 出す ように 言いました。Müəllim hesabatı təqdim etməyi dedi.母 に 早く 帰る ように 言われました。Anam tez qayıtmağımı dedi.Birbaşa sitat: 「出して ください」と 言いました. Dolayı: 出す ように 言いました. Qadağa üçün 〜ない ように: 遅れない ように 言われました – gecikməməyimi dedilər.Feillər: bu qəlibdə 言う, 頼む, 注意する, 伝える işlənir.
 ex: 先生は 学生に 宿題を 出すように 言いました。 = Müəllim tələbələrə ev tapşırığını təhvil verməyi dedi.
 ex: 医者に 薬を 飲むように 言われました。 = Həkim mənə dərman içməyi dedi.
 ex: 母に 夜 遅く 帰らないように 言われました。 = Anam mənə gecə gec qayıtmamağı dedi.
G11. 〜て くる / 〜て いく | meaning: gedib-gəlmək; dəyişərək gəlmək / getmək
 pattern: feil て-forması くる / いく
 explanation: 〜て くる / 〜て いく iki mənalıdır. Birincisi hərəkət: 買って きます – gedib alıb gəlirəm, 持って いきます – götürüb gedirəm.İkincisi zamanla dəyişmə: くる keçmişdən indiyə, いく isə indidən gələcəyə.寒く なって きました。Soyuqlaşmağa başladı. (indiyədək, davam edir)これ から 人口 が 減って いく でしょう。Bundan sonra əhali azalacaq.Zaman oxu: keçmiş ──〜てくる──▶ indi ──〜ていく──▶ gələcək. Dəyişikliyin istiqamətini göstərir.
 ex: ~コンビニで 飲み物を 買って きます。 = Marketə gedib içki alıb qayıdıram.
 ex: 日本の 冬は だんだん 寒く なって きました。 = Yaponiyada qış tədricən soyuqlaşdı.
 ex: これから 人口は 減って いく でしょう。 = Bundan sonra əhali azalacaq, yəqin ki.
 ex: 傘を 持って いきましょう。 = Çətir götürüb gedək.
